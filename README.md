# Trinity-zhcn — 红色沙漠（Crimson Desert）Mod 菜单（简体中文版）

基于 [ReXooGen/Trinity](https://github.com/ReXooGen/Trinity)（vTweak by Lian）二次开发的简体中文汉化与修复版，适配 TU 2.00.00 – 2.02.00（PE 1.0.0.2658 – 1.0.0.2850）。

## ✨ 本版特色

### 我们独有的修复（上游未解决）
- **中文搜索输入** — 菜单搜索框 / 文本框支持中文输入法直接输入（打字时自动挂载 IME 输入上下文并显示拼音组字 / 候选框，结束时恢复；UTF-8 编码整字退格，可直接用中文物品名搜索、给传送点命名）
- **地图标记传送** — 修复 TU 2.00 地图标记坐标无法捕获的问题（目的地更新钩子方案）
- **游戏变速** — 修复 TU 2.00 变速失效（主帧更新钩子）
- **手柄掉帧** — XInput 轮询缓存（4ms 窗口），连接手柄时帧数恢复
- **中文字体完整性** — 动态字形收集：语言包全文 + 引擎本地化文本池扫描，界面文字不缺字
- **角色识别** — 修复装备编辑器中克里夫 / 德米安 / 翁卡互相误判、错配的问题。当前操控角色改用**结构判定**（possessor 回环定位被控角色本身），不再依赖装备签名；非操控角色用**整容器装备多数派**识别；被控角色的容器也不会再被其它角色页签认领——因此背包里带着别人的专属装备时，各页签依然各归其位
- **稳定性加固** — 修改游戏画面设置（分辨率 / 全屏 / HDR / 帧生成）不再崩溃（swapchain 重建 SEH 保护 + 仅成功时重建）；菜单缩放不会触发字体图集溢出（g_scale 与字体尺寸双重上限防护）
- **染色预览** — 染色界面右侧预览图实时跟随所选槽位
- **染色性能** — 染色页选中德米安 / 翁卡不再掉帧（通道批量读取 + 按角色缓存组件与装备快照，重型身份扫描仅在切换角色时执行一次）
- **内置中文语言包** — 简体中文直接编译进 DLL，无需外部语言文件；修复 CI 编码转换（/utf-8）与中文字形图集问题，中文完整显示、菜单语言切换流畅不崩溃
- **简易完美招架 / 闪避** — 按住防御 = 100% 完美招架（免伤 + 弹开敌人），按下闪避 / 翻滚键 = 100% 完美闪避（免伤）
- **自由飞行滑翔** — 空中按住升降键平滑滑翔，松开立即恢复重力，飞行体验更流畅
- **自定义坐标传送** — 传送页新增「自定义坐标」子菜单：手动输入 X / Y / Z 直接传送，支持从当前玩家位置一键填充再微调，专治地图标记不准确或无法直接到达的地点
- **完整中文汉化** — 全菜单界面 + 染色/装备编辑 UI（槽位名、角色名、材质、强化 / 精炼、孔位状态）+ 装备属性与技能描述

### 同步上游 TU 2.00 / 2.01 / 2.02
- TU 2.00.00 – 2.02.00 适配（PE revision 检测与各版本签名 / 偏移策略）
- 伴侣染色隔离（按角色同步）
- 库存稳定性修复（700 槽位、Error 298648703 系列）

- 2.02（PE 2850）环境 / 大气实体解析、移动组件与领域偏移适配
- 服务器容器认领收紧：仅「独立存活角色 + 桶数与客户端一致」的容器可作为服务器权威，避免商人 / 规划副本容器被误认

### 已知限制（TU 2.02 / PE 2850）
游戏更新后部分原生路径签名失效，相关功能自动降级而不是崩溃：
- 属性直写保护（stat-commit）缺失 → 上帝模式 / 无限体力等退回当前角色锁定
- 简易招架 / 闪避的原生 JustCore 路径缺失 → 仅保留战斗时序（combat-timing）路径
- 传送「目的地更新」缺失 → 该子项停用（地图标记传送本身正常）
- 染色持久化（upsert）缺失 → 染色可生效，但重启后不保留
- 添加物品 / 槽位扩展仍受引擎服务端校验限制（与上游结论一致）

## 📥 安装
1. 将 `Trinity.asi` 放入游戏根目录（与 `CrimsonDesert.exe` 同目录）
2. 启动游戏，按 `INSERT`（手柄：LB + 下）打开菜单

## 🛠 从源码构建
```bash
cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=Release
cmake --build build
```
